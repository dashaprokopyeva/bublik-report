Сотрудники подразделения

Методика: показатели «в смену» и среднее время разговора вычисляются индивидуально для каждого сотрудника, затем усредняются по выбранной области. Конверсия берётся непосредственно из столбца «% успешных по дозвону». Сотрудники без смен исключаются из расчётов на смену. Длительность Excel хранит в долях суток и переводится в часы/минуты. При загрузке нового файла отчёт полностью пересчитывается.

Рейтинг по группам прозвона

Рейтинг строится отдельно внутри каждого направления прозвона по всем операторам этого направления из подразделения. Показаны только операторы 3-го кластера. Категория 1–4 в расчёте ранга не участвует. Ранг 1 — лучшие 20%, ранг 5 — последние 20%. При показе всех рангов сортировка идёт по возрастанию суммы до следующего ранга; достигшие ранга 1 находятся в конце. Средняя стоимость успешки рассчитывается как сумма зарплаты от успешек всех операторов направления прозвона, делённая на общее число их успешек.

Норма рассчитывается по листу «график»: 4 проработки за смену супервайзера (10, 8 или Д). Если график отсутствует, норма не рассчитывается. Проработки: параллелька, групповой тренинг, обучение, работа с ИС. Групповые активности: групповой тренинг, собрание, планерка. Остальные виды — дополнительные активности. Конверсия рассчитывается только для подходящих индивидуальных активностей с полной историей трёх последующих смен.
